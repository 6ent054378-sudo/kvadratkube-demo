Сайт `kvadratvkube26.ru` перестал открываться не из-за наших правок.
Beget (хостинг, где лежит сайт) 1–2 ноября 2026 попал под кибератаку:
по их официальной хронологии злоумышленники запустили вредоносное ПО
«для удаления данных с серверов», после чего все серверы отключили от сети.
Виртуальный хостинг восстанавливают поэтапно, данные — из резервных копий.

## Чтобы вернуть домен

Вариант 1 (ничего не делать): как только Beget поднимет виртуальный хостинг,
сайт откроется сам — DNS уже указывает на их сервер. После восстановления
нужно перезалить `index.html` (в нём новая отправка форм) по FTP
`deploy@stavevee.beget.tech`.

Вариант 2 (вернуть за 3 минуты, без ожидания Beget): перевести домен
на GitHub Pages. Делает Дмитрий в своём кабинете RU-CENTER (nic.ru),
пароли никому передавать не нужно:

1. nic.ru → «Домены» → `kvadratvkube26.ru` → «DNS-серверы» →
   указать `ns3-l2.nic.ru`, `ns4-l2.nic.ru`, `ns5-l2.nic.ru` (сохранить).
2. Там же → «DNS-записи»: убрать старые A, добавить четыре A для `@`:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   для `www` — CNAME `6ent054378-sudo.github.io`.
3. Написать нам — включаем домен в настройках GitHub Pages и HTTPS.

## 20.11.2026: переключили домен на GitHub Pages

Клиент написал, что сайт «наконец-то запустили», но не играет видео 101.
Проверка прода: HTTP 200, HTTPS не работает (443 отказан из 4 стран),
FTP/SSH не отвечают, панель Beget пишет «аккаунт находится в очереди на
восстановление», файловый менеджер/FTP/SSL/сайты недоступны.

Причина 404 на видео: 12.10 файлы заливались в
`/stavevee.beget.tech/public_html/assets/video/…`, а корень сайта —
`/kvadratvkube26.ru/public_html/`. На прод видео никогда не попадало;
на GitHub Pages оно лежит и отдаётся (`200`, `video/mp4`, range).

Что сделано:

- в репозиторий добавлен `CNAME` с `kvadratvkube26.ru`;
- в GitHub Pages задан custom domain `kvadratvkube26.ru` (сборка `built`);
- в DNS Beget (зона `kvadratvkube26.ru`, NS `ns1/ns2.beget.com`) A-записи `@`
  заменены с `87.236.19.118` на `185.199.108.153` и `185.199.109.153`;
- `www` удалён как A-узел и создан заново как CNAME
  `6ent054378-sudo.github.io`;
- MX/TXT (почта, SPF) не тронуты — почта Beget продолжает работать.

Важно: панель Beget в режиме восстановления, изменения DNS применяются
«в течение 15 минут». После распространения DNS нужно проверить HTTPS
(сертификат GitHub Pages выпускается автоматически) и включить
`https_enforced`. Формы на GitHub Pages идут через
`https://kv-lead.pulka-leads.workers.dev/` (проверен, доступен из РФ),
`lead.php` там не выполняется.

Когда Beget восстановит аккаунт: решить, оставаться ли на GitHub Pages
(быстрее и с HTTPS) или вернуть сайт на Beget, дозалив
`index.html`, `assets/video/app101.mp4`, `assets/video/app101-poster.jpg`
и перевыпустив SSL.
