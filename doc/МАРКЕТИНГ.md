# МАРКЕТИНГ (единый документ, Р-12) – КвадратВкубе, ремонт, Ставрополь

> Собран из артефактов Р-01–Р-11. Верстать только после чек-листов ниже.

## 1. Персонаж-локомотив

Семья 30–40 из новостройки в ипотеке, живёт на съёме. Боли: смета x2, аванс→пропали,
сроки +1,5 мес, кривизна. Нужно: заехать к дате, точная цена, не ездить. Страхи:
предоплата, доплаты, грязь. Словарь: «сколько под ключ?», «материалы входят?»,
«когда заезд?». Подробно: research/01_ца.md.

## 2. Тезисы (выжимка из 30)

15 лет · приложение 101 (этапы/бюджет/фото) · гарантия 1 год · оплата по этапам
после приёмки · скидки партнёров · выезд бесплатно + смета 24ч · тарифы 13/17/22 ·
объекты: Салют 1-к, дом 250 м², Радонеж, санузел, Михайловск 150 м² · Дмитрий сам
на объектах. Подробно: research/02_компания_30_тезисов.md.

## 3. Оффер 4U (hero)

«Дизайнерский ремонт квартир в Ставрополе [за 45 дней]» + sub «Смета за 24 часа ·
гарантия 1 год по договору». Банк из 25+ вариантов – в переписке.

## 4. Структура заголовков (v3)

Шапка → Hero → Квиз → Замер (КЭВ) → Работы → Почему-мы → Контроль →
FAQ → Контакты → (технические: Спасибо, /privacy). Подробно: research/05_структура.md.

## 5. Акция ODC

Замер до конца месяца → клининг в подарок + фикс цены. Дату и 2-й подарок –
с Дмитрием. Подробно: research/04_оффер_акция_квиз_воронка.md.

## 6. Квиз

4 вопроса (объект с фото / площадь / состав / сроки) + «Не знаю» + подарок +
телефон с компенсацией («3 варианта расчёта»). Без попапов на мобиле.

## 7. Воронка (гипотеза)

10 000 ₽ → ~65 кликов → ~1,3 заявки → ~0,6 замера → ~0,2 сделки.
Цель 3 сделки = ~90 000 ₽ или бесплатные каналы. Подробно: research/07_воронка.md.
